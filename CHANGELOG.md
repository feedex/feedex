# Changelog

All notable changes to `feedex/feedex` are documented in this file.

## [1.0.0]

### Stable release
- Core contracts/capabilities model finalized for v1.
- Granular module/capability contracts retained as additive non-breaking extension points.
- Capability-driven multi-adapter usage guidance documented.
- Registry/factory architecture stabilized for plugin ecosystem.

## [0.1.7]

### Docs
- Added capability-driven usage example for multi-adapter clients.
- Added explicit core v1.0 scope freeze documentation.

## [0.1.6]

### Added
- Granular module/capability contracts for flexible adapter implementations.
